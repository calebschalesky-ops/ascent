# EXP-03: The tactical view at 25%, and maneuvers with ghost lines
Source: done point 2 ("the tactical view"); VISION §7a "The tactical view slows time to 25%… it never stops"; §16 M1, T1; BRIDGE §12b
Start state: new skirmish, seed 3
| Step | How | Player does | Player sees (checkable) | Vision ref |
| 1 | ui | Opens the tactical view (one key) | A hologram-style view of the battle; time runs at 25% (probe: time scale 0.25, never 0) | §7a, T1 |
| 2 | ui | Looks at ships in it | Each ship shows its four shield arcs; enemy arcs show only what his sensors know (seeing is not knowing) | T1 "shield arcs"; §7a "Seeing is not knowing" |
| 3 | ui | Selects a ship and picks a maneuver: broadside pass on an enemy | A ghost line of the maneuver's path and its time to completion, before he commits | BRIDGE §12b rule 3 |
| 4 | ui | Commits it | The ship flies along the shown path (probe: ship position stays within a set distance of the ghost path) | §12b |
| 5 | ui | Orders each of the other five maneuvers in turn: crossing the line, flanking arc, boarding run, defensive wheel, fighting withdrawal | Each previews as a ghost line and is flown; each is visibly a different shape | M1 "first six" |
| 6 | ui | Cancels a maneuver halfway with a new order | The ship breaks off with a short believable turn, not a snap (probe: heading rate within its turn limit) | §12b rule 4 |
| 7 | probe | Gives the same maneuver to a Helm 9 and a Helm 3 captain | The Helm 9 ship finishes sooner and holds the path tighter | §12b "High Helm flies them tighter and faster" |
| 8 | ui | Has order lines on screen | Every standing order is drawn as a line from ship to target | T1 "order lines" |
| 9 | ui | Closes the tactical view | Time returns to 1x; the battle never paused | §7a |
